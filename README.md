# AllToZed — чтобы ИИ не забывал, где вы остановились

Несколько простых текстовых файлов, которые кладутся в проект. Благодаря им
любой AI-помощник (Zed и другие) после открытия проекта видит, над чем вы
работали, что решили и что делать дальше — вам не нужно объяснять это
заново.

## Какую проблему решает

Когда вы работаете с ИИ, вся «память» разговора живёт **только в чате**.
Закрываете вкладку, сервер падает, открываете новый чат — и помощник
забывает всё: что вы делали, что решили, что осталось. Приходится
объяснять с нуля.

AllToZed решает это: главное выносится в файл `TASK.md` в папке проекта —
**памятка на столе, а не в голове собеседника**. Новый помощник прочитал
памятку за пару секунд и продолжает с того же места.

## Как это работает (три пункта)

1. **Вы просто работаете в чате.** Помощник сам молча заполняет памятку:
   важное решение принято, шаг завершён, план изменился. Ничего
   настраивать и вводить не нужно.
2. **Чат «умер» или стал длинным** — открываете новый чат в той же папке
   и говорите одно слово: **«Продолжаем»**. Помощник читает памятку,
   отвечает в 2–3 строки: «Делали X, готово Y, дальше Z — идём?» Вы
   говорите «идём» — и работа продолжается с того же места.
3. **Меняете компьютер** — памятка хранится в git вместе с кодом.
   Скопировали проект на другую машину (git clone), открыли, сказали
   «продолжаем». Всё.

## Что лежит в этой папке

| Файл | Зачем |
|---|---|
| `AGENTS.md` | «Инструкция для ИИ»: что читать при открытии проекта, когда обновлять памятку, что нельзя делать. Zed читает её **автоматически** — специально ничего не запускать. |
| `TASK.md` | Сама памятка: над чем работаем, что сделано, что дальше, что решили. Пока пустой шаблон — заполняет помощник в процессе работы. |
| `.gitignore` | Говорит git, какие локальные файлы (папку `.notes/`) не сохранять. |

Это **не программа**: установка, сборка и зависимости не нужны — только
обычные текстовые файлы.

## Как включить в своём проекте

Скопируйте три файла в папку вашего проекта. Для Windows: откройте
PowerShell в папке AllToZed и выполните (пути поправьте под свой):

```powershell
Copy-Item AGENTS.md,TASK.md,.gitignore C:\мои\проекты\мой-проект\
cd C:\мои\проекты\мой-проект
git add AGENTS.md TASK.md .gitignore
git commit -m "AllToZed init"
```

- `git add` / `git commit` — сохранить файлы в истории проекта. Это нужно,
  чтобы памятка переезжала вместе с проектом (ситуация 3 выше).
  Если git не используете — просто скопируйте файлы — всё работает
  локально, без переноса на другие машины.
### Без команд: через Проводник Windows

Не хочется открывать PowerShell — копируйте файлы мышкой:

1. Откройте в Проводнике папку AllToZed (там, где лежат файлы из этого
   репозитория).
2. Выделите три файла — `AGENTS.md`, `TASK.md` и `.gitignore` (клик по
   первому, затем Shift + клик по последнему). `gitignore` начинается с
   точки — не пугайтесь, это просто имя, Проводник показывает его
   нормально.
3. Правая кнопка → «Копировать». Откройте папку своего проекта → пустое
   место → правая кнопка → «Вставить».

Всё, файлы на месте. Без git памятка будет работать локально; чтобы она
переезжала на другую машину — скопируйте весь проект целиком (папка
по папке) или выполните `git add` / `git commit` из блока выше.

Если в проекте **уже есть** свой `AGENTS.md` — не перетирайте его:
вставьте содержимое скопированного файла в существующий (или спросите
помощника — он сам аккуратно сольёт).

Ещё проще: откройте свой проект в Zed и скажите помощнику
**«Создай AllToZed для этого проекта»** — он сам скопирует всё
необходимое, заполнит памятку и сохранит.

## Обычные команды

| Вы говорите | Что происходит |
|---|---|
| «Продолжаем» / «продолжи» / «далее» | Новый чат подхватывает нить по памятке. |
| «Сохрани контекст» | Помощник дописывает памятку до финального вида — перед закрытием вкладки, уходом со смены или сменой машины. |
| «Создай AllToZed для этого проекта» | Включить протокол в другом проекте. |
| «Убери AllToZed» | Убрать из проекта: сначала «сохрани контекст», потом удалить `AGENTS.md` (или только его секцию протокола) и `TASK.md`. Помощник больше не будет вести памятку. |

## «Продолжаем» своими словами

Слов по умолчанию — «продолжаем» / «продолжи» / «далее», но вы можете их
заменить или дополнить.

Откройте файл `TASK.md` в своём проекте (в Zed или любым редактором). Вверху
файла есть строка вида:

_Триггеры: «продолжаем» / «продолжи» / «далее» …_

Перепишите её по-своему — например так:

_Триггеры: «го» / «подними нить» / «read TASK.md»_

Сохраните. С этого момента помощник реагирует только на ваши слова и
перестаёт реагировать на те, что вы убрали. Строка лежит внутри проекта —
у каждого проекта могут быть свои триггеры, и она переезжает вместе с
ним.

## Для нетерпеливых: команда `resume` одной строкой

Можно сделать так, чтобы в новом чате не надо было ничего писать —
команда `/resume` сама поднимет нить (не хотите возиться — просто скажите фразу «продолжаем», результат тот же):

1. В папке `%APPDATA%\zed` создайте файл `resume.md` с текстом:

```
Прочитай TASK.md и продолжи активную задачу по протоколу AGENTS.md:
проверь, что памятка в порядке, сориентируй в 2–3 строках, жди «идём».
```

2. В настройках Zed (`settings.json`, открывается: Ctrl+Shift+P →
«settings») добавьте:

```json
{ "agent": { "custom_commands": { "resume": "%APPDATA%/zed/resume.md" } } }
```

> Zed активно обновляется: если в вашей версии этого ключа нет — загляните
> в JSON-схему настроек (в редакторе настроек подсказки подскажут) —
> имя могло поменяться. Сам протокол от команды не зависит.

## Частые вопросы

**Это не программа? Что может сломать?** Ничего: файлы — обычные
текстовые заметки. Максимум, что может случиться, — помощник забыл
обновить памятку. Тогда она просто устареет: попросите «сохрани
контекст» — допишется.

**Помощник будет ходить молча и что-то записывать?** Да, это и есть
смысл: запись происходит на «милях» (решение, готовый шаг, смена
плана) — без вашего участия.

**Всякая ли среда это поддержит?** Любой ИИ, который умеет читать файлы в
папке проекта, и Zed (автоматически), и Claude Code, и Cursor — откройте
папку, скажите «продолжаем».

**Секреты в памятке попадут?** Протокол это запрещает; помощник так и
делает.
